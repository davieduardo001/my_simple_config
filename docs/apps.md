# Apps — o que o setup instala

## Via Homebrew (CLI)

| Pacote | Função |
|---|---|
| `git`, `gh` | Versionamento + GitHub CLI |
| `eza`, `bat`, `zoxide`, `fzf` | `ls` melhorado, `cat` com syntax highlight, `cd` inteligente, fuzzy find |
| `btop`, `fastfetch` | Monitor de sistema / info na tela |
| `tmux` | Abas/splits no terminal |
| `starship` | Prompt do shell |
| `ripgrep`, `fd`, `lazygit` | Busca rápida, find, git TUI |
| `unzip`, `curl`, `wget`, `jq` | Utilidades base |
| `opencode` | Agente de IA no terminal (CLI de coding) |
| `syncthing` | Sincronização de arquivos entre dispositivos |

## Via Flatpak (apps gráficos)

| App | Flatpak ID | Função |
|---|---|---|
| Chromium | `org.chromium.Chromium` | Browser |
| Firefox | `org.mozilla.firefox` | Browser (flatpak = sem customização userChrome) |
| OnlyOffice | `org.onlyoffice.desktopeditors` | Suite office (docx/xlsx/pptx) |
| GNOME Calculator | `org.gnome.Calculator` | Calculadora |
| LocalSend | `org.localsend.localsend_app` | Transferência de arquivos na rede local |

## Gerenciador de arquivos

Não instala Nemo — usa o **padrão do DE**:
- GNOME → **Files** (`nautilus`)
- XFCE → **Thunar**
